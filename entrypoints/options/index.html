Core behavior

PayAttention pauses HTML audio and video whenever a document becomes hidden.

Keyboard shortcuts

Alt + Shift + A toggles a tab-close exception. Alt + Shift + P toggles the extension.

Import, export, and privacy

Exports contain settings and site rules only. Activity history is deliberately excluded.

Local-only design

PayAttention has no server, account, analytics, advertisements, telemetry, or remote code. It does not read page text. It only detects and controls media elements, observes document visibility, and—when enabled—changes the browser tab’s mute state.
