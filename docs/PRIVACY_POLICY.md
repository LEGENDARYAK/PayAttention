# PayAttention Privacy Policy

**Effective date: July 13, 2026**

PayAttention is designed to operate entirely on the user’s device.

## Data collection

PayAttention does not collect, transmit, sell, rent, share, or monetize personal information. It has no user accounts, server, advertising, analytics, telemetry, tracking pixels, or remote code.

## Local extension data

PayAttention stores the following information in browser extension storage:

- User-selected settings
- Permanent site rules
- Temporary site exceptions and their expiration times
- Tab-only exceptions in session storage
- An optional recent activity log, when explicitly enabled

The optional activity log records only the website hostname, timestamp, action taken, media-item count, and whether fallback tab muting was used. It does not record page titles, page text, media titles, browsing history, audio, video, form data, or account information.

All stored data remains on the user’s device and is removed when the extension is uninstalled, subject to the browser’s own storage behavior.

## Page access

PayAttention uses broad website access because it must detect and pause media elements on pages the user visits. The extension observes document visibility and interacts with audio and video elements. When the optional all-audio fallback is enabled, it may also change a tab’s mute state.

PayAttention does not read page text for profiling or transmit page information anywhere.

## Third parties

PayAttention does not disclose data to third parties and does not integrate with third-party analytics or advertising services.

## Changes

Material changes to this policy will be reflected in the extension listing and in an updated version of this document.
