# Chrome Web Store Listing Draft

## Name

PayAttention

## Short description

Pause media when you leave a tab and keep your attention connected to what you play.

## Detailed description

PayAttention helps you watch and listen intentionally. When you switch away from a tab, it pauses the audio or video you left behind instead of letting it continue as background noise.

Key features:

- Automatically pause music and videos when a tab becomes hidden
- Optional all-audio fallback that mutes unusual players and Web Audio
- Optional resume when you return—only for media PayAttention paused
- Permanent and temporary site exceptions
- One-click “allow until tab closes” mode
- Per-site pause, mute, pause+mute, or allow behavior
- Discreet in-page notifications with an optional Resume button
- Toolbar status badge and keyboard shortcuts
- Local import/export and optional recent activity history

PayAttention is private by design. It has no account, server, analytics, ads, telemetry, or remote code. Settings and rules stay in your browser.

## Single-purpose statement

PayAttention pauses or mutes media when the user stops viewing its tab, helping the user maintain intentional attention.

## Permission justification

**Read and change data on all websites:** Required to detect and pause audio/video elements on pages the user visits. PayAttention does not collect page content.

**Tabs:** Required to identify the active tab, display a per-tab toolbar badge, and optionally mute/unmute a tab as an all-audio fallback.

**Storage:** Required to save local settings, rules, and optional activity history.
